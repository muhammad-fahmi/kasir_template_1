# Kasir Split POS

Template kasir (POS) layout split 2 kolom: katalog produk di kiri, panel keranjang sticky di kanan. Tema Orange/Slate. Cocok untuk tablet atau desktop kasir.

## Fitur
- Layout split responsif (desktop 2 kolom, mobile bottom nav)
- Pencarian produk + filter kategori chips
- Panel keranjang sticky
- Diskon persen
- Struk, riwayat transaksi, dan pengaturan toko (localStorage)
